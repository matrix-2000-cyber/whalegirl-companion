# 正面待机角色素材

`front.png`、旧眨眼帧与动作素材来自 [dsh-pet 0.3.7](https://github.com/PC2005-cloud/dsh-pet)，随附上游 MIT 许可证 `DSH-PET-LICENSE`。当前通话只使用正面图及程序绘制的待机动作，旧动作视频不参与通话。

待机呼吸约五秒一轮，脚底固定，眨眼用连续眼睑曲线。指尖注视仅在用户明确要求后临时启用，结束或超时后恢复正视。

说话嘴部取自本项目 `whalegirl-seated-atlas.png` 的原唇形阴影，去掉周围肤色后贴合当前脸部，由实际播放音频的波形和频带连续控制。暂停、停顿或打断时闭嘴，没有音频分析时保持原嘴，不使用循环假节奏。这是声音节奏同步，未提供文本音素时间轴。
