# 0.4.0 发布检查与隐私边界

检查日期：2026-10-26。发布物为 Windows x64 在线安装预览版。本说明覆盖本次公开源码与实际 EXE 内嵌资源，不是第三方安全认证，也不保证未来依赖永远无漏洞。

## 隐私检查

发布前从实际 EXE 提取 `app.zip`、`scripts.zip`，逐文件比较干净源码和 SHA256 清单；并对解压后的文本、二进制素材、原生 EXE 字符串作检查。扫描已知本机密钥值与私人账号/路径时只输出是否命中，不公开敏感值。

本次发布不包含 `.env.local`、真实 QQ 账号、原作者 DSH profile、聊天会话、记忆数据库、日志、配对资料、TLS 私钥、浏览器 cookie、签名私钥、原始摄像头画面或私人参考截图。公开的联系人数字是测试示例。源码不通过原工作目录的 Git 历史发布；更新基于原先审查过的公开仓库。

另在公开提交元数据中发现 GitHub 默认署名使用了联系邮箱。经仓库所有者授权，主分支已有提交的作者/提交者邮箱改为 GitHub 隐藏邮箱，后续发布也使用隐藏邮箱；源码内容保留。旧提交编号、第三方克隆与 GitHub 缓存可能仍保留旧元数据，本检查无法保证其已从所有历史缓存撤回。

安装包不嵌入任何模型账号或额度。模型、Node、Python、PowerShell、FFmpeg 均在用户安装时独立下载。发布页另附 EXE 的 `SHA256SUMS.txt`，可用于核对下载文件；它不是数字签名。

## 隔离与运行边界

- 安装版只使用自己的 `DSH_HOME`、工作目录、会话和记忆；不复制原作者或用户其他部署的记忆。
- 专用本机端口 3180/3191/3192，避免接管原部署。对话与网页健康信息须匹配该安装实例，端口冲突会报错。
- 记忆、账号设置、证书和本机日志保留在独立数据目录；Windows ACL 限制到当前用户与 SYSTEM。
- 不修改全局 PATH、执行策略、代理、防火墙或杀毒配置，不请求管理员权限。
- 显式关闭 DSH 的三项可选遥测；不添加本项目的统计上报。
- 下载的运行组件和模型使用 HTTPS 与固定 SHA256；ZIP/TAR 解压拒绝路径越界、链接和不支持的条目，核查清单、长度或 CRC。

运行时仍会按你的选择向模型服务发送对话/摄像头抽帧，向语音服务发送朗读文本。面部和手部关键点、SenseVoice 识别在本机运行。用户自己的模型提供方可能记录请求；不能据此声称“完全离线”或“任何信息都不出电脑”。DSH 会保存本机对话与记忆，迁移或报告故障时应主动脱敏。

## 依赖修复与验证

新增证书依赖已选用 `selfsigned@5.5.0`，避免旧版 node-forge 的已知问题。DSH 0.2.1-rc.2 在独立 npm 根目录覆盖 zod 4.6.7、undici 8.12.3、fflate 0.8.3、MCP client 2.4.0；这是本项目的兼容性修复，不改全局 DSH。发布时 npm 官方审计对安装版网关与该 DSH 安装树均报告 0 项已知漏洞。该结论只对应检查时的 npm 漏洞库，不涵盖所有 Python、浏览器或模型风险。

验证包含插件 110 项、桌面/网关 54 项、ZIP 安全 3 项、TAR 安全 2 项自动检查；还进行了空白目录完整联网安装、独立服务启动、模型静态文件读取与本机 ASR 预热检查。测试使用专用数据目录，没有复制作者模型账号，也没有代用户登录或发出付费对话请求。

当前限制：尚未在全新虚拟机覆盖所有 Windows 版本；没有代码签名；安装向导的完整屏幕交互流程未完成自动化验证；摄像头、扬声器和不同模型账号的完整通话需用户完成首次配置后验证。不要把安装/HTTP 检查等同于全部真机通话已验证。
