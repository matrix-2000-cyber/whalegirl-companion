# 使用与排障

先确认电脑网页显示“已连接”。先发文字，再点声音设置中的“试听”，最后开启摄像头和视频陪聊。

- **摄像头**：浏览器需要授权。开启后可以选择是否向对话模型分享画面。面部和手势追踪在本机运行；后台画面理解会把抽帧发送给已配置的视觉服务。
- **指尖注视**：手靠近镜头，伸出食指，角色目光采用自拍镜像方向平滑跟随；手离开后回正。
- **挥手回礼**：张开手掌左右挥动，有持续判断和冷却，不会逐帧复制你的动作。
- **表情回应**：观察微笑、眉部收紧、闭眼、抬眉、嘴角下压、点头/摇头等动作；弱信号不立即触发回应。
- **主动话题**：开镜头后主动问候，空闲时再发起少量话题；正在说话、输入、播放声音或未回应时抑制。可关闭开关。
- **语音**：开始陪聊后分段识别，回复按句朗读。“开口打断”为试用，受回声消除、扬声器音量和麦克风影响。
- **音效**：声音设置可分别试听笑、哭、叹气。短音效与TTS音色不保证完全一致，未做真人声音克隆。

| 问题 | 检查 |
|---|---|
| 网页打不开 | 确认3092本机服务运行，先用 `pwsh -File gen/start-desktop.ps1 -NoOpen` 查看错误；不要使用手机HTTPS地址代替电脑入口 |
| 页面未连接 | 确认DSH 3080、网关3091、插件和目标会话已配置 |
| 有文字没声音 | 点击试听，检查网络和Python环境；Edge TTS需要联网 |
| 听不见你 | 检查麦克风授权、FFmpeg和SenseVoice模型，查看 `.mobile-gateway/desktop-error.log` |
| 看不见你 | 检查摄像头授权、分享画面开关、视觉模型配置；未授权或没看清时不会假装看见 |
| 手势/表情没识别 | 检查 `.desktop-runtime/vision` 与models是否完整；改善光线、避免遮挡，检查浏览器Worker报错 |
| 旧记忆没找到 | 确认meow-memory启用、主人原会话工作目录正确；视频会话与原会话必须使用同一个记忆目录 |
| 回复慢 | 查看 `/api/qq-bridge/runtime` 的 `mobile.lastTurn`；文字快而音频慢通常是TTS网络等待 |

不要公开配对页、日志中的个人对话、证书文件或整个DSH profile。排障时只提供脱敏后的报错与版本信息。
