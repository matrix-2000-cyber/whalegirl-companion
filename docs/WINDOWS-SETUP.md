# Windows 安装预览版

适用 Windows 10/11 x64。无需预装开发工具，不需要管理员权限。下载 `WhaleGirl-Setup-0.4.0-win-x64.exe` 后运行，选择专用安装文件夹，点击“安装 / 修复”。安装需要联网；首次下载超过 1.7 GB，建议预留至少 5 GB 空间。模型源在部分网络不可达时，向导会报告失败；可调整自己的网络后重试，已校验的下载文件会复用。向导不会关闭系统的安全检查。

安装完成后：

1. 点击“打开模型设置”，在本机 DSH 页面登录自己的模型服务，设置默认对话模型和可用视觉模型。选用支持工具调用与图像输入的模型。
2. 返回向导点击“开始聊天”。先输入文字验证，再启用麦克风和摄像头；浏览器会询问设备权限。
3. 以后双击桌面的“鲸鱼娘”。“鲸鱼娘设置”可以重新打开模型配置。默认聊天网址为 `http://127.0.0.1:3192/`。

安装不含模型账号、额度、QQ登录或原作者记忆。免费默认朗读使用 Edge TTS 网络服务；摄像头关键点和语音识别在本机执行，画面分析和对话仍需要你配置的模型服务。模型服务可能按用量计费。

## 独立存放与升级

- 程序和运行环境：`%LOCALAPPDATA%\Programs\WhaleGirlCompanion`。
- 私密配置、会话、记忆与日志：`%LOCALAPPDATA%\WhaleGirlCompanionData`。
- 安装版专用端口：3180 对话管理、3191 网关、3192 网页，均绑定本机回环地址。
- 更新或修复时使用相同程序目录；数据目录保留。不要把私密数据目录上传到 GitHub，也不要分享其中的整份日志。
- 源码部署默认端口仍为 3080/3091/3092。安装版不替换、终止或读取其 DSH profile 和记忆。
- 目前是在线安装器，不是离线整包；不包含 Android/iPhone 安装包，不负责 Apple 签名。

“直接连接下载”仅影响向导启动的子进程，不改电脑代理。默认采用当前网络/代理。不会修改全局 PATH、执行策略、防火墙或杀毒设置；依赖安装在程序自己的目录。部分 npm/Python依赖有自己的构建/初始化脚本，只从声明的软件包源获取。

## 故障与移除

模型未登录时不能聊天，但可以打开模型设置。端口被其他程序占用时会拒绝接管；保留错误信息，解决占用后重试。下载哈希不符会拒绝执行该文件。向导关闭可停止本次安装；可能留下可复用的下载缓存。

关闭网页不会自动终止后台服务。暂不提供系统“应用和功能”卸载项。移除前先关闭该安装目录启动的鲸鱼娘进程，然后删除程序目录和桌面入口；只要保留独立数据目录，记忆与设置就会保留。确认不再需要时才手动删除数据目录。备份和迁移数据前先停止该安装版服务。

## 从干净源码构建

在 Windows、PowerShell 7 与系统 .NET Framework C# 编译器可用的环境运行：

```powershell
pwsh -File installer/build.ps1 -Source . -Output out/setup
```

只对已经审查、没有运行数据的源码副本构建。构建器会把 Source 中的全部文件纳入资源，不能指向你日常使用、含密钥或缓存的工作目录。`--inspect-package <空文件夹>` 可从 EXE 提取内嵌 ZIP，不执行安装，供独立检查。安装包使用普通用户权限启动，尚未购买代码签名证书。
